Multi-Model Routers (Bring Your Own AI)

At Seaynic Labs, our products are BYO-AI (Bring Your Own AI). To make this seamless, we highly recommend using a "Multi-Model Router". These tools let you swap between local and cloud models effortlessly, combining all your keys into a single, unified interface.

L

LiteLLM (Local Proxy)

LiteLLM runs locally on your machine and translates over 100+ AI providers (including Ollama, Groq, NVIDIA, and Hugging Face) into the standard OpenAI format. It's the ultimate tool for seamless BYO-AI.

pip install litellm litellm --model ollama/llama3
O

OpenRouter (Cloud Router)

If you prefer a cloud solution without local installation, OpenRouter is a unified API that automatically routes your requests to the cheapest and fastest cloud models available, including many free tiers.

Sign up at openrouter.ai and generate a single API key to access hundreds of models.
⚡

The Ultimate Setup: True Agility

For maximum agility, you can run LiteLLM locally and connect it directly to OpenRouter! This gives you a single local address (localhost:4000) that acts as the ultimate gateway. You can instantly hot-swap between offline Ollama models and massive cloud OpenRouter models right from your terminal—without ever needing to change the API settings in your apps again.

export OPENROUTER_API_KEY="sk-..." litellm --model openrouter/meta-llama/llama-3-8b-instruct
